# 体重进度可用性增强设计

## 范围

本轮提升趋势图、记录列表、关键数据解释和加载体验。暂不处理访问权限，不修改数据库结构，也不引入图表库或新的运行时依赖。

## 近期趋势图

### 时间范围

- 提供 `7天｜30天｜全部` 三个范围。
- 默认选择“全部”。
- 范围只影响“近期趋势”，不影响长期计划图。
- 7 天和 30 天以当前用户最新一条体重记录日期为范围终点，而不是系统今天，确保没有近期记录时仍能看到连续数据。
- 范围内只有一条记录时仍显示数据点和计划参考，不绘制无意义的实际折线。
- 范围内没有记录时显示明确空状态。

### 数据点提示

- 桌面端悬停或聚焦数据点时显示提示卡。
- 触屏端点击数据点时显示提示卡，再次点击其他点时更新。
- 提示内容包括日期、实际体重、当天计划体重、与计划的方向性差值。
- 提示卡不得超出图表容器；靠近左右边缘时自动调整对齐方向。
- 数据点使用可聚焦的交互目标并提供可读标签，不能只依赖颜色或鼠标悬停。
- 离开图表、按 Escape 或切换时间范围时关闭提示。

## 体重记录列表

- 桌面端和手机端均默认显示最近 7 条。
- 超过 7 条时显示“查看全部记录（N）”。
- 展开后显示全部记录，按钮改为“收起记录”。
- 切换用户时自动恢复默认收起状态。
- 不再通过 CSS 的 `nth-child` 隐藏行，避免表头或结构变化造成错误隐藏。

## 关键数据解释

### 当前体重

- 当前体重卡在数值下方显示最近记录日期，例如“记录于 10月6日”。
- 无体重记录时显示“暂无记录”，不伪装成计划初始体重。

### 今日计划

- 顶部计划与实际进度区域显示“今日计划 87.2 kg”。
- 计划开始前显示开始体重，计划结束后显示最终目标体重，与现有计划体重计算规则一致。
- 今日计划与方向性差值相邻展示，帮助用户理解“高于／低于计划”的比较基准。

## 加载与失败状态

- 首次加载用户和数据时只显示结构骨架，不显示种子或演示数据。
- 骨架覆盖头部操作、计划摘要、统计卡、趋势和记录区域的主要形状。
- 骨架使用轻微明暗过渡，并遵循 `prefers-reduced-motion`；减弱动效模式下保持静态。
- 加载完成后一次性展示真实数据。
- 共享数据读取失败时显示错误提示，并允许展示本地预览；预览必须明确标注，避免被误认为已同步数据。
- 切换用户时保留当前页面结构并显示局部忙碌状态，不重新闪现另一用户的数据。

## 状态色令牌

在 `:root` 中统一定义：

- `--success: #2f7d4f`
- `--success-soft`: 成功状态浅色背景
- `--warning`: 未达计划或需注意状态
- `--warning-soft`: 警示状态浅色背景
- `--danger`: 删除或破坏性操作
- `--danger-soft`: 危险状态浅色背景

已有 `--lag`、`--bad` 和硬编码成功色逐步替换为语义令牌。品牌主色 `--green` 和正文色 `--ink` 保持不变，状态色只表达状态，不用于装饰。

## 组件边界

- 计划与差值计算继续复用 `lib/weight-calculations.ts`。
- 趋势范围筛选和提示状态留在 `RecentTrendChart` 附近，不进入数据仓库层。
- 记录展开状态由 `WeightTracker` 管理，并在切换用户时重置。
- 骨架屏作为独立组件，避免把加载占位逻辑散落到每个区域。

## 验证

- 默认范围为全部，7 天和 30 天以最新记录为终点正确筛选。
- 单点和空范围不会产生无效 SVG 坐标。
- 桌面悬停、键盘聚焦和触屏点击都能读取相同提示内容。
- 提示卡在图表两端不溢出，Escape 与范围切换能关闭。
- 两端默认显示 7 条记录，展开、收起和切换用户行为正确。
- 当前体重日期与今日计划正确显示。
- 初次加载不显示演示数据，失败预览有明确标识。
- 状态样式只使用统一令牌，成功、警示、危险含义一致。
- lint、单元测试、服务端构建和 GitHub Pages 构建通过。

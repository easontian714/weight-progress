# 近期趋势与长期计划双图设计

## 目标

将当前混合展示实际体重与年底目标的单张图拆成两张图，避免短期数据集中在左上角，同时利用趋势区域现有的纵向空间。

## 近期趋势

- 横轴范围取当前已有体重记录的最早日期至最新日期。
- 纵轴根据实际体重数据自动缩放，并保留适量上下留白。
- 使用实线和圆点展示每次记录，并用虚线展示同一日期范围内的计划体重。
- 横轴显示起止日期；每个数据点保留日期与体重提示。

## 长期计划

- 横轴范围保持完整计划周期，即 2026-09-01 至 2026-12-31。
- 纵轴围绕计划起始体重与目标体重设置。
- 使用虚线展示从起始体重到目标体重的完整计划路线。
- 使用实线展示截至最新记录日期的实际体重，未来日期不延长实线；为避免遮挡线条，只标记最新实际体重点。
- 标记最终 80.0 kg 目标。

## 布局与响应式

- 两张图纵向排列在同一趋势面板中，各自带简短标题。
- 桌面端充分利用现有留白；移动端保持横向自适应，不产生横向滚动。
- 沿用现有绿色配色、线条语言和图例，不改变页面其他区域。

## 每周目标

- 默认仅展示与当前进度最相关的 5 个里程碑，兼顾最近已结算节点与最近未来目标。
- 其余里程碑通过“查看全部目标”展开，展开后可再次收起。
- 未来节点继续保留编辑入口，折叠只改变展示数量，不改变数据。

## 数据与行为

- 继续读取现有 Supabase 体重记录和计划数据，不修改数据库结构。
- 新增、编辑或删除体重后，两张图随现有状态自动更新。
- 无数据或仅一条记录时仍能稳定绘制，不出现除零或坐标异常。

## 验证

- 运行 GitHub Pages 静态构建和现有站点构建。
- 检查近期图的数据不再挤在左侧，长期图完整显示计划周期。
- 发布后验证页面与静态资源可访问。
